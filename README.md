# Piko — сайт

Чёрно-белый анимированный сайт проекта Piko. Чистый HTML + CSS + JS, без сборки и зависимостей
(кроме шрифтов Google Fonts — без них сайт тоже работает, с системными).

## Файлы
- `index.html` — страница
- `style.css` — стили и анимации
- `script.js` — граф на фоне, курсор, 3D-карточки, терминал
- `favicon.svg` — иконка

## Запуск
Откройте `index.html` в браузере.

## Публикация на GitHub Pages (piko.is-a.dev)
1. Создайте репозиторий (например `1mow.github.io` или `piko`) и загрузите все файлы из этой папки в корень.
2. **Settings → Pages → Deploy from a branch → main / (root) → Save.**
3. После одобрения pull request в is-a-dev/register: **Settings → Pages → Custom domain** → `piko.is-a.dev` → Save.
4. Включите **Enforce HTTPS**.
